# Release notes

## Initial submission

This is the initial skills-only Zilliz plugin submission for the public plugin directory shared by ChatGPT and Codex.

The plugin packages provider-neutral workflows for operating Zilliz Cloud and Milvus through the zilliz-cli. It includes cluster, database, collection, vector, index, partition, import, backup, monitoring, billing, PrivateLink, access-control, onboarding, status, and diagnostic workflows.

The submission excludes platform-specific slash commands, marketplace metadata, undeclared MCP dependencies, credentials, and private review materials.
