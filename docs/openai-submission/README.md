# OpenAI submission materials

This directory contains public, reusable copy for the Zilliz plugin submission. It is intentionally excluded from the release archive.

The following information must never be committed:

- Reviewer usernames, passwords, API keys, or tokens.
- Real organization, project, cluster, database, or collection identifiers.
- Business verification documents.
- Private partner correspondence or submission identifiers.
- Customer or production data.

Enter sensitive review information directly in the OpenAI submission portal or store it in an approved secret manager. Use placeholders in the public test cases.

Before each submission, review every file in this directory against the current portal fields and confirm the legal and support URLs with the responsible Zilliz teams.
